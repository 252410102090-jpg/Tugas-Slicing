# Tugas Slicing Website Landing Page - Ruang Seduh Coffee

Repository ini berisi hasil slicing landing page kedai kopi **Ruang Seduh** menggunakan HTML5, Plain CSS3, dan JavaScript DOM Manipulation.

Fitur Utama
- **Responsive Design**: Tampilan optimal untuk PC, Tablet, dan Smartphone.
- **Interactive Mobile Menu**: Navigasi hamburger dengan animasi transisi smooth.
- **Form Handling (DOM)**: Interaksi pengiriman pesan reservasi secara realtime tanpa reload halaman.
- **Smooth Scrolling**: Transisi perpindahan section yang halus.
